# 密码哈希算法用例

汇总常见的密码哈希 / 派生算法测试用例，按算法分文件夹存放，每个文件夹内为 `index.go`。

| 算法 | 常见分类 | 实现状态 |
|------|----------|----------|
| bcrypt | 自适应密码哈希函数 | 已实现 |
| Argon2id | 内存困难型密码哈希函数 | 待实现 |
| scrypt | 内存困难型密码派生函数 | 待实现 |
| PBKDF2 | 基于迭代次数的密码派生函数 | 待实现 |
| SHA-256 | 通用哈希函数，不适合直接存密码 | 已实现 |
| MD5 | 通用哈希函数，不能用于密码存储 | 待实现 |

说明：待实现的算法目前只有结构占位（含 `main` 方法与实现思路注释），未编写具体逻辑，也未引入新依赖。
