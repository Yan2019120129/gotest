| **[bcrypt](bcrypt/index.go)**     | 自适应密码哈希算法（Adaptive Password Hash），基于 Blowfish 设计，专用于密码存储       | 生成不可逆密码哈希，提高密码离线破解成本    | 防止数据库泄露导致密码明文暴露，通过 salt 和 cost 降低彩虹表、暴力破解效率 | 密码 → 生成随机 salt → 设置 cost → Blowfish扩展密钥计算 → 输出 `$2a$cost$salt$hash`      | Go：`bcrypt.GenerateFromPassword()` 生成哈希；`bcrypt.CompareHashAndPassword()` 校验；核心参数 cost（默认10）       | 用户登录密码存储、账号认证系统                | 仅增加 CPU 计算成本，无内存困难；高并发登录增加CPU压力 | 哈希泄露后仍可离线破解；弱密码仍容易被字典攻击；cost过高可能造成DoS | 生态成熟；兼容性强；支持逐步升级 cost           | GPU并行破解优势明显；安全性低于Argon2id；计算资源消耗增加接口延迟 | **Argon2id**（推荐）、scrypt    |

## 分类总结

| 类型             | 算法                                  | 主要目标           |
| -------------- | ----------------------------------- | -------------- |
| **密码存储算法**     | Argon2id、bcrypt、scrypt、PBKDF2       | 提高密码破解成本       |
| **通用哈希算法**     | SHA-256、MD5                         | 数据摘要、完整性校验     |
| **推荐排序（密码存储）** | Argon2id > bcrypt ≈ scrypt > PBKDF2 | 安全性排序          |
| **禁止用于密码存储**   | MD5、SHA-256                         | 速度过快，无法抵抗GPU破解 |
